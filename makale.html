Frontend Geliştirme

Frontend, kullanıcıların web sitesine doğrudan gördüğü ve kullandığı bölümlerin geliştirilmesini ifade eder.

Bir web sayfasının yapısını oluşturmak için HTML, görünümünü düzenlemek için CSS ve etkileşimlerini sağlamak için JavaScript kullanılabilir.

HTML

HTML, web sayfasının yapısını oluşturur. Başlıklar, paragraflar, bağlantılar, görseller, tablolar ve formlar HTML ile oluşturulabilir.

CSS

CSS, HTML ile oluşturulan sayfanın görünümünü düzenlemek için kullanılır. Renk, yazı tipi, boşluk ve sayfa düzeni gibi özellikler CSS ile belirlenebilir.

JavaScript

JavaScript, web sayfalarına etkileşim ve dinamik davranış kazandırmak için kullanılabilir.
